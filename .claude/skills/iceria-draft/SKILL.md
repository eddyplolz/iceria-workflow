# Draft an Iceria page

1. **Pick the template.** Copy the matching file from `templates/`. Done when the page type and
   its section order (MoS 8.3, 9.6, 10.3 or 11.4) are fixed.
2. **Gather the facts.** Read the member's notes, the nation's page in `canon/nations/` if it
   exists, and every page in `canon/` the subject touches (geography, culture zone, shared
   history). Done when each fact you plan to use has a source: the member's notes or a named page.
3. **Ask** the member about every gap the notes leave, before you fill it. A political outcome or a
   character's choice is the member's to make: offer options.
4. **Write** the page in wikitext, following `style/writing-checklist.md`: in-world voice, sentence
   case, bold in the lead only, figures for 2000, a reference on every figure. Fill every infobox
   line you have a fact for and delete the rest. Delete the template's comments.
5. **List the NEW facts**: every name, date, figure or relation the draft adds that no page in
   `canon/` holds, each with the line it appears on. Facts that touch another nation are marked
   "needs that nation's agreement".
6. Hand the draft to `iceria-canon-check`, then `iceria-self-audit`.

Done when the draft has every section its type takes, each with prose, and the NEW-facts list is
complete.
